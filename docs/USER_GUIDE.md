## 1. 准备与安装

### 1.1 你需要准备

- 桌面版 Google Chrome 116 或更高版本（Windows / macOS / Linux）。手机、Safari、Firefox 不支持。
- 能正常访问 www.youtube.com 的网络。
- 一个可用的 sub2api 服务地址（Base URL）和 API Key，Key 所属分组需要有所选翻译模型的权限。
- 翻译**没有可读字幕**的视频时，还需要一个语音识别服务，例如本项目附带的本地识别服务（见[第 4 节](#4-无字幕视频与语音识别)）。
- 从源码构建时：Node 24.15.0 与 pnpm 10.33.0（见 [README](../README.md#环境要求)）。

### 1.2 构建扩展

在项目根目录执行：

```sh
pnpm install
pnpm build
```

构建完成后，扩展文件位于 `.output/chrome-mv3`。

### 1.3 在 Chrome 中加载

1. 在地址栏打开 `chrome://extensions`。
2. 打开右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择项目中的 `.output/chrome-mv3` 文件夹。
4. 列表中出现「同听 Tongting」后，点击浏览器工具栏的拼图图标，把「同听」固定到工具栏，方便点击。
5. **刷新已经打开的 YouTube 标签页**。扩展加载之前打开的页面不会自动接入。

### 1.4 更新扩展

重新执行 `pnpm build` 后，在 `chrome://extensions` 中点击「同听」卡片上的重新加载按钮，然后刷新 YouTube 页面。

注意：重新加载或更新扩展会清空「仅保存在浏览器会话」的 API Key，需要重新输入（见 [2.3](#23-api-key-与保存位置)）。

## 2. 配置 sub2api

点击工具栏「同听」图标 → 「设置」，或在侧栏「设置」标签点击「打开完整设置」。设置页左侧有「模型连接」「识别与播放」「术语表」「数据与隐私」「快捷键」「演示模式」几个分区（以实际界面为准）。

也可直接在侧栏「设置 → CONNECTION / 模型连接」填写地址、Key 和翻译模型，点击「保存连接设置」。自定义地址保存后需单独授予访问权限，再点击「检查连接」。模型列表可在侧栏直接获取；协议、记住凭证等更多选项在完整设置中。保存期间继续编辑的内容会保留，需再次保存才能生效。

若删除凭证或迁移保存位置时清理失败，会显示错误并保留「重试清理 Key／令牌」按钮；正在使用的旧凭证立即撤销，但应在重试成功后才视为本地副本已彻底删除。

推荐顺序：填写服务地址 → 授予访问权限 → 保存 API Key → 选择模型 → 检查连接。

### 2.1 服务地址（Base URL）

在「模型连接」→「sub2api 服务地址（Base URL）」中填写你的服务根地址，然后点击「保存地址」。以下写法等价：

```text
https://your-sub2api.example.com
https://your-sub2api.example.com/
https://your-sub2api.example.com/v1
```

规则：

- 带不带 `/v1` 都可以，扩展会统一处理，不会拼出 `/v1/v1`。误粘贴完整端点（`/v1/responses`、`/v1/chat/completions`、`/v1/models`）也会回退到根地址。
- 如果服务部署在反向代理的子路径下（例如 `https://example.com/sub2api/v1`），保留子路径即可。
- 必须使用 `https://`。`http://` 只允许 `127.0.0.1`（本机调试；不支持 `localhost`，它可能解析到 IPv6 上的其他进程）。
- 地址中不能包含用户名密码、`?` 查询参数或 `#` 片段。
- 请填写**最终的 API 地址**。为了防止 Key 被发往其他站点，扩展不会跟随重定向。

### 2.2 授予访问权限

保存地址后点击「授予访问权限」，Chrome 会弹出权限确认框，只申请访问**这一个地址的 origin**（例如 `https://your-sub2api.example.com/*`）。

- 扩展的 manifest 声明了较宽的「可选访问范围」，这是为了支持任意用户自建的域名；实际只会在你点击按钮时申请你填写的那一个 origin。
- 未授予权限时，扩展不会向该地址发送任何请求，状态显示「尚未授予访问 … 的权限」。
- 更换服务地址后需要为新地址重新授权。
- 已授予的权限可在 `chrome://extensions` →「同听」→「详情」→「网站访问权限」中查看或移除。

### 2.3 API Key 与保存位置

在「API Key」中粘贴 Key（示意：`<你的 Key>`），点击「保存 Key」。保存成功只表示 Key 已保存，**不表示可用**，请继续做[检查连接](#27-检查连接)。

保存位置有两种：

| 选项                   | 保存在                                       | 何时失效                                                          | 风险说明                                                                                                     |
| ---------------------- | -------------------------------------------- | ----------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| 默认勾选「记住在本机」 | 扩展自己的 IndexedDB（仅扩展页面与后台可读） | 重载/更新/停用扩展、重启浏览器后仍保留；删除 Key 或卸载扩展后清除 | 保存在本机浏览器配置目录，不会同步到其他设备；**不是安全保险箱**，能访问这台电脑浏览器配置的人或程序可能读取 |
| 主动取消「记住在本机」 | `chrome.storage.session`                     | 关闭浏览器、重新加载/更新/停用扩展后失效，需要重新输入            | 只存在于浏览器内存中                                                                                         |

两种方式下，Key 都只允许扩展自身的可信页面和后台读取（YouTube 页面里的内容脚本无法读取；旧版本保存在 `chrome.storage.local` 的 Key 会在首次读取时自动迁移并删除旧副本），不会出现在 YouTube 页面、字幕消息、界面快照、日志或导出的设置文件中；界面只显示末 4 位掩码。侧栏可修改「记住在本机」后点击「保存连接设置」，无需重新输入当前有效 Key；完整设置页随「保存 Key」提交所选位置。

升级到设置版本 v2 时，旧版默认临时保存改为记住在本机，之后主动选择的临时模式会保留。仍能读取到的临时 Key 会迁移；如果 Chrome 已经清空旧的临时 Key，需要重新保存一次。保存失败时不会清空输入框，可直接重试。

删除 Key：点击「删除 Key」。使用旧 Key 的进行中请求会被中止，正在运行的翻译会停止并提示。

本地识别服务的配对令牌（见[第 4 节](#4-无字幕视频与语音识别)）使用同一个「记住在本机」选项。

### 2.4 接口协议

「接口协议」有三个选项：

- **自动检测**（默认）：检查连接时先尝试 Responses 接口，只有服务明确不支持时才改用 Chat Completions。检测结果会显示在选项下方；修改服务地址或协议后检测结果会清空，需要重新检查。
- **Responses** / **Chat Completions**：手动指定。自动检测结果与你的服务实际情况不符时使用。

### 2.5 选择翻译模型

新安装与重置设置默认使用 **`gpt-5.6-luna`**，已有模型设置不会被自动覆盖。Luna 是 GPT-5.6 系列轻量版，本次已通过用户 sub2api 服务的字幕翻译与流式实测；可用性仍以你当前账号的检查结果为准。

1. 保存地址和 API Key，并授予服务访问权限。
2. 在侧栏或完整设置点击「获取模型列表」。下拉框只展示服务实际返回的 **GPT-5.6 及以上文本模型**；隐藏旧版、图像、音频、实时音频等型号。
3. 选择带「字幕翻译推荐」的 `gpt-5.6-luna`，或选择其他候选。
4. 侧栏点击「保存连接设置」；完整设置点击「保存模型」。选中下拉项只更新草稿，保存后才生效。
5. 点击「检查连接」。列表里有模型不代表当前可调用；例如本次 `gpt-5.4-mini` 虽被服务列出，但调用返回 429。

「刷新模型列表」不会改动正在编辑的模型。列表为空、获取失败或模型使用自定义别名时，仍可在「模型 ID（可手动填写）」中输入并保存。先前保存的旧模型仅在手填框保留，不进入下拉候选。

### 2.6 其他参数

| 设置         | 默认值 | 说明                                                                                        |
| ------------ | ------ | ------------------------------------------------------------------------------------------- |
| 推理参数     | 不发送 | 可选 `none` / `low`。服务或模型可能不接受；如果检查连接报「不接受某个参数」，改回「不发送」 |
| 流式返回     | 关     | 需要服务支持；开启后检查连接会单独验证流式结果                                              |
| 单次请求超时 | 15 秒  | 3–120 秒；网络慢或模型慢时可调大                                                            |

### 2.7 检查连接

点击「检查连接」后，扩展会**真实请求**你的服务，并逐项显示结果。「小规模翻译」会发送一条很短的测试文本，可能产生少量费用。

| 检查项                  | 含义                                         | 失败时的下一步                                                 |
| ----------------------- | -------------------------------------------- | -------------------------------------------------------------- |
| 访问权限                | 是否已授予该地址的访问权限                   | 点击「授予访问权限」                                           |
| 地址可达                | 能否连上服务地址                             | 检查网络、地址拼写、证书，见[故障排查](#91-sub2api-连接与翻译) |
| 认证                    | Key 是否被服务接受                           | 重新填写 Key                                                   |
| 模型列表                | 服务是否返回模型列表（失败不影响手动模型）   | 手动填写模型 ID                                                |
| 选定模型                | 当前模型 ID 是否存在、是否有权限             | 检查分组的模型权限或更换模型                                   |
| 小规模翻译              | 用当前协议和模型实际翻译一小段文本并校验结果 | 按提示检查协议、模型、推理参数                                 |
| 流式返回                | 开启流式时，服务是否真的按流式返回并正常结束 | 关闭流式返回                                                   |
| 语音识别 / 本地识别服务 | 所选识别服务是否可用                         | 见[第 4 节](#4-无字幕视频与语音识别)                           |
| 语音合成 / 系统语音     | 所选合成方式是否有当前目标语言可用的声音     | 见[3.7](#37-字幕--配音)                                        |

结果状态：「通过」「失败」「不支持」「未检测」。

- 「通过」只表示**最近一次检查**实际请求成功，不代表之后一定可用。
- 检查之后修改了配置，界面会提示结果可能已过期，请重新检查。
- 语音识别与语音合成在「识别与播放」区块分别检查。本地识别服务和系统语音的检查不产生费用。
- 选择 sub2api 语音识别或语音合成时，检查按钮下方有「允许实际调用 sub2api 音频接口」勾选框：只有勾选后才会实际调用一次（识别上传 1 秒测试音，合成朗读「你好」），可能产生少量费用；勾选只对本次检查有效。不勾选时显示「未检测（需要允许实际调用）」。
- sub2api 识别检查「通过」只说明接口与认证可用，测试音频不是人声，不代表识别准确度。

### 2.8 术语表（可选）

「术语表」分区可以添加固定译法（原文 → 译文），例如人名、产品名。修改术语表会使旧的翻译结果失效并重新翻译（可能产生费用）。

## 3. 开始翻译

### 3.1 入口

- **工具栏弹窗**：点击「同听」图标。显示当前标签页视频、「翻译为」、开始/暂停按钮、翻译服务状态，以及「打开侧栏」「字幕工作台」「设置」。
- **侧栏**：在弹窗中点击「打开侧栏」，或通过 Chrome 的侧边栏按钮选择「同听」。侧栏有「翻译」「字幕」「设置」三个标签，视频继续在原 YouTube 页面播放，翻译字幕显示在原播放器上。
- **快捷键**：Alt+T 开始 / 暂停 / 继续翻译当前标签页，Alt+C 显示 / 隐藏翻译字幕（见[第 7 节](#7-快捷键)）。

关闭弹窗或侧栏**不会**停止翻译；重新打开会显示当前真实状态。

### 3.2 开始翻译

1. 在 www.youtube.com 打开一个普通视频（不是首页、搜索页）。刚安装或更新扩展时，先刷新该页面。
2. 点击工具栏「同听」图标，确认「当前标签页」显示了视频标题。
3. 选择「翻译为」的目标语言，点击「开始翻译」。
4. 翻译字幕出现在播放器画面上。展开侧栏「翻译」标签底部的「播放与翻译详情」，可查看视频信息、字幕来源、已翻译数量、失败数量、最近一次请求往返耗时和实际模型；没有数据时显示「未知」。音频采集状态和错误提示直接显示，无需展开详情。

如果服务未配置，「开始翻译」按钮不可用，并提示缺少什么。

**建议从工具栏图标或快捷键开始**：对于需要捕获标签页声音的场景（无字幕视频、始终识别语音），Chrome 要求你先在该标签页点击扩展图标或按快捷键，详见 [4.4](#44-标签页音频捕获)。

### 3.3 状态含义

#### 同步优先与连续播放

侧栏「翻译 → PLAYBACK / 播放」默认选择「同步优先」，缓冲目标默认 10 秒，可选 5 / 10 / 20 秒。这里的秒数是**准备好的视频内容长度**，不是预计等待时间。

- 开始时，如果视频正在播放，扩展先暂停画面，连续译文达到目标后自动继续；如果你原本就暂停了视频，准备完成后仍保持暂停。
- 播放期间持续准备后面的内容。译文即将耗尽时重新缓冲；拖动进度后，从新位置准备，旧位置配音停止。
- 无完整字幕时，本地服务每次预读约 20 秒音轨，准备约 45–60 秒前方内容。视频暂停不妨碍预读；「暂停翻译」会取消预读。
- 失败时显示原因与重试入口。切换「连续播放」、停止翻译或关闭缓冲后，已经暂停的视频需要你点击播放，避免意外自动播放。
- 要听中文，请把「输出」选为「字幕 + 配音」，目标选中文，并检查系统中文声音。缓冲条表示译文已就绪；配音在相应时间朗读，不是提前生成的完整音轨。

无字幕预读需本地服务启用 `--youtube-preload`，安装方法见 [本地服务预读说明](../services/asr-local/README.md)。只支持可公开访问的普通录播；登录限制、受保护视频与直播不适用。旧版本地服务或只配置云端识别时，可切回「连续播放」。实际准备时间受网络、识别和翻译速度影响，处理赶不上播放时仍会暂停。

| 状态（以实际界面为准）  | 含义                                                     |
| ----------------------- | -------------------------------------------------------- |
| 未配置服务              | 缺少服务地址、API Key 或访问权限                         |
| 非视频页                | 当前标签页不是已接入的 YouTube 视频页                    |
| 可开始                  | 已配置，当前视频尚未开始翻译                             |
| 启动中                  | 正在读取字幕或准备识别、翻译服务                         |
| 运行中                  | 翻译会话正在工作                                         |
| 正在暂停 / 翻译已暂停   | 你暂停了翻译                                             |
| 正在停止                | 正在中止请求、停止配音、释放音频采集；完成后状态才会更新 |
| 出错                    | 显示原因和可执行的下一步按钮（如「检查设置」「重试」）   |
| 正在连接 / 正在重新连接 | 界面与扩展后台的连接尚未建立或正在恢复                   |
| 演示中                  | 演示模式，数据是示例，见[第 6 节](#6-演示模式)           |

### 3.4 「暂停视频」「暂停翻译」「停止并释放音频」的区别

三者是独立的操作：

| 操作           | 怎么做                                                    | 效果                                                                                                                                                                                 |
| -------------- | --------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 暂停视频       | 在 YouTube 播放器上暂停                                   | 只暂停视频。翻译会话保持；开启「暂停视频时暂停配音」（默认开）时配音同时暂停。恢复播放后从当前位置继续，不会连播暂停前积压的旧句子                                                   |
| 暂停翻译       | 点击「暂停翻译」或按 Alt+T                                | 不再产生新的翻译、识别和配音，当前配音停止、原声恢复；已获得的字幕与笔记保留。正在播放的视频可继续播放，因缓冲而暂停的视频保持暂停。点击「继续翻译」恢复翻译；需要彻底释放请用下一项 |
| 停止并释放音频 | 展开侧栏「翻译 → 播放与翻译详情」，点击「停止并释放音频」 | 结束本次会话：中止进行中的请求、停止配音、停止标签页音频捕获和识别、恢复原声。已保存的字幕记录保留。之后需要重新「开始翻译」，捕获声音时可能需要再次点击工具栏图标                   |

注意：客户端中止请求不代表服务端一定不计费。

### 3.5 语言与翻译风格

- **视频语言**：默认「自动识别」，也可手动指定。下拉框显示你的选择，下方显示实际使用的字幕轨道语言或检测到的语言；悬停可查看完整说明。
- **翻译为**：可选简体中文（默认）、繁體中文、English、日本語、한국어、Español、Français、Deutsch。这是界面选项，某种语言的翻译质量、识别和配音是否可用取决于你的模型、识别服务和系统声音，**不代表已经实测支持**。
- 翻译中切换目标语言：旧的翻译与配音会作废，按新语言重新翻译（可能产生费用），不会两种语言混播。
- **翻译风格**：自然流畅（默认）、忠实原文、简洁易读、专业术语优先。风格只影响译文的表达，不能提高原文字幕或语音识别的准确率。

### 3.6 字幕显示

侧栏「翻译」标签 →「CAPTIONS / 字幕」（背景不透明度在「设置 → 更多设置」）：

| 设置                    | 默认     | 说明                                                          |
| ----------------------- | -------- | ------------------------------------------------------------- |
| 在视频上显示翻译字幕    | 开       | 也可用 Alt+C 切换；只影响显示，不停止翻译                     |
| 双语字幕（译文 + 原文） | 开       |                                                               |
| 字幕位置                | 画面底部 | 底部 / 中间 / 上方                                            |
| 字号                    | 22 px    | 12–48 px                                                      |
| 背景不透明度            | 75%      |                                                               |
| 字幕时间微调            | 0 秒     | −10 到 +10 秒，正数表示字幕延后显示。字幕普遍偏早或偏晚时调整 |

翻译字幕是同听自己绘制的层，与 YouTube 自带字幕（CC）互相独立。

### 3.7 字幕 + 配音

1. 在「翻译方式」→「输出方式」选择「字幕 + 配音」。
2. 默认使用**系统语音**。「配音声音」默认「自动选择（优先本机声音）」，下拉框列出浏览器实际提供、适用于当前目标语言的声音，并标注语言和「本机声音／联网声音」。下方显示实际将使用的声音；展开「浏览并试听全部 N 个声音」可逐个试听，点击声音名称即可选用。试听不改变已保存的选择；选择自动保存到本机，重新打开扩展、刷新扩展或重启浏览器后继续使用。已保存的声音暂不可用时会提示并自动选用兼容声音，不会抹去原选择。
3. 调整「配音音量」「配音语速」（0.5–2 倍，默认 1 倍）。
4. 「原声处理」默认选择**全程静音**：同声传译期间只播放译文配音，中文句间停顿、等待翻译和拖动进度条时也不会冒出原声。暂停翻译、停止翻译或切回「仅字幕」后恢复原声。升级前保存的设置也默认采用全程静音；静音只影响播放，不会把语音识别输入静音。
5. 想同时听原文时，可主动选择「保留原声」，再调整「原声音量」。此模式下「配音时降低原声」默认开启，只在配音发声时将原声降至设定比例（默认 30%），句间恢复。全程静音期间调整 YouTube 音量会记住新值，在退出同传后恢复。
6. 系统语音可点击「试听」确认声音可用；配音进行中不能试听，请先暂停翻译。「停止试听」只停止试听，不会中止同传会话。选择 sub2api 语音合成时，通过完整设置的语音合成检查验证服务。

未打开 YouTube 视频时，也可以在侧栏「设置 → VOICE / 配音声音」中选择和试听，无需先填写 API Key。

系统配音和试听不调用 sub2api、不消耗其额度；字幕翻译仍消耗模型额度。声音数量取决于系统与浏览器。如果只有一个声音，可展开「如何添加更多声音？」：Mac 在「系统设置 → 辅助功能 → 阅读与朗读（旧版为朗读内容）→ 系统声音 → 管理声音」中下载目标语言的声音（[Apple 说明](https://support.apple.com/zh-cn/guide/mac-help-cn/mh27448/mac)）。安装后点「刷新声音」；声音列表变化或返回扩展窗口时也会自动重新读取。仍未出现时重开 Chrome；部分系统声音不会提供给扩展。

识别／增量字幕的译文通常晚于原句到达。新译文最多允许在原句结束后 15 秒到达并进入配音队列，最多等待 8 秒；超过窗口会跳过，避免越积越慢。导出的字幕仍保留原始时间。切换识别服务、分段长度、来源策略或配音后端会释放旧资源并按新配置运行；暂停中的会话在继续时应用新配置。

注意：

- 配音报错时翻译字幕照常工作；「全程静音」不会因此突然播放原声。若需恢复原声，请切回「仅字幕」、选择「保留原声」或暂停翻译。系统声音不可用的解决方法见[故障排查](#93-配音)。
- 系统语音由操作系统或浏览器提供，**可能需要联网**，不能保证完全离线。
- 设置页「识别与播放」中可以把语音合成改为「sub2api 语音接口」，但该能力需要你的服务支持且经过实测。勾选「允许实际调用」后检查语音合成；未检测通过时配音不会启用。本轮使用系统声音，未验证云端合成。
- 同一时间只有一个标签页可以使用同听的音频（配音或语音识别）。在另一个标签页开始时，会先释放原标签页的资源再启动新的。

## 4. 无字幕视频与语音识别

### 4.1 字幕来源

设置页「识别与播放」→「字幕来源」（侧栏「设置」标签也可修改）：

| 选项                                 | 行为                                               |
| ------------------------------------ | -------------------------------------------------- |
| 优先视频字幕，缺失时识别语音（默认） | 有可读字幕就用字幕；没有时使用已配置的语音识别服务 |
| 仅使用视频已有字幕                   | 没有可读字幕时提示无法翻译                         |
| 始终识别视频声音                     | 忽略字幕，始终捕获声音并识别                       |

字幕读取方式有两种，界面「字幕来源」会显示实际使用的是哪种：

- **完整字幕轨道**：能读到整条字幕时间轴，可以提前翻译后续字幕（「预翻译后续字幕」，默认开，会提前产生翻译请求）。
- **增量字幕**：读不到完整轨道时，改为读取播放器当前显示的字幕。只覆盖已经播放过的部分，并且需要保持 YouTube 自带字幕（CC）开启。

画面中烧录的文字不算可读字幕，同听不做文字识别（OCR）。

**没有可读字幕、又没有配置语音识别服务时**，会明确提示缺少识别服务，视频照常播放，不会用示例字幕代替。

### 4.2 本地识别服务

本项目附带一个可选的本地识别服务（Python + faster-whisper），在你自己的电脑上识别音频。安装、启动、停止、模型下载、性能与排障请完整阅读 **[ASR_LOCAL.md](ASR_LOCAL.md)**。要点：

- 扩展**不会**自动安装或启动它，需要你先在终端手动启动，并保持运行。
- 服务只监听 `127.0.0.1`（默认端口 8765），需要配对令牌才能调用。首次启动会在终端打印配对令牌，之后可以用服务提供的命令再次查看（具体命令见 ASR_LOCAL.md）。
- 首次启动需要下载识别模型，下载和加载期间服务显示「加载中」。
- 识别速度取决于你的 CPU/硬件和所选模型，不保证所有电脑都能跟上播放速度。

在扩展中启用：

1. 设置页「识别与播放」→「语音识别服务」选择「本地识别服务」。
2. 「本地服务地址」保持 `http://127.0.0.1:8765`（改过端口则相应修改），点击「保存地址」。
3. 点击「授予本机服务访问权限」。
4. 把终端显示的令牌填入「配对令牌」，点击「保存令牌」。
5. 在「模型连接」中勾选「允许产生计费调用」后点击「检查连接」，查看「本地识别服务」一项（以实际界面为准）。「通过」表示服务在线且模型已就绪；令牌会在第一次实际识别时验证。

### 4.3 sub2api 语音识别

「语音识别服务」中也可以选择「sub2api 语音接口（需检测）」并填写识别模型 ID。是否可用取决于你的 sub2api 部署与分组。在设置页「识别与播放」勾选「允许实际调用」后点击「检查语音识别」，可以实际验证接口与认证（会产生一次计费调用）。本轮只验证了本地 Whisper，云端识别**尚未经过真实服务验收**，请以你的检查结果为准。

### 4.4 标签页音频捕获

识别需要捕获正在播放视频的标签页声音。Chrome 对此有两项要求和一个副作用：

- **需要你先在该标签页调用扩展**：在 YouTube 视频标签页上**点击工具栏的「同听」图标**（再点「开始翻译」），或**按快捷键 Alt+T**。只在侧栏里点击按钮可能不被 Chrome 视为授权，会提示「无法捕获此标签页的声音」。
- 捕获只在你点击开始后发生，不会在安装或打开页面时悄悄开始；侧栏「翻译状态」会显示「正在采集本标签页音频」。
- **捕获期间原声由扩展回放**：Chrome 捕获标签页声音后，该标签页原本的声音输出会被接管，你听到的原声实际上由同听重新播放。因此「原声音量」滑块在识别模式下生效；停止捕获后恢复为标签页自己播放。识别使用的是调整音量**之前**的声音，降低原声不会影响识别。

### 4.5 识别积压

如果识别速度长期跟不上播放速度，界面会显示「识别积压约 N 秒」；积压过大时会跳过部分音频并提示。可以暂停视频等待，或在本地识别服务中换用更小的模型（见 ASR_LOCAL.md）。跳过的部分会记入覆盖范围的缺口。

## 5. 字幕记录与工作台

### 5.1 侧栏「字幕」标签

- 翻译进行中显示实时字幕；没有进行中的会话时，显示本机保存的该视频字幕记录（同一视频可能按目标语言和来源有多条记录，可在「本地记录」中切换）。
- 当前播放的字幕会高亮并自动滚动。你手动滚动后不再自动跟随，点击「跟随播放」恢复。
- 点击字幕时间可以让原视频跳转到该位置。
- 每条字幕会标注「等待翻译」「正在翻译」「翻译失败」「临时识别」「结束时间为估计」等状态（以实际界面为准）。翻译失败的条目可以用「重试失败的 N 条」重新翻译。

### 5.2 字幕工作台

从弹窗「字幕工作台」或侧栏「设置 → 打开字幕工作台」进入（在新标签页打开）。侧栏字幕列表的原文／译文／双语选项及覆盖范围位于「显示与覆盖详情」中：

- **左侧「字幕记录」**：本机保存的所有字幕记录，标注「完整轨道」或「部分字幕」、条数和更新时间。可以删除单条记录；删除记录不会删除该视频的笔记和收藏。
- **中间字幕列表**：与侧栏相同的搜索、收藏、复制、导出功能。
- **右侧「笔记」**：按视频保存，自动保存在本机（显示「已保存」「保存失败，内容仍在输入框中」等状态）。「引用当前字幕」或字幕旁的引用按钮会插入带时间的字幕引用。字幕获取失败或删除字幕记录都不会清空笔记。
- 源 YouTube 标签页关闭后，工作台仍可查看已有记录和笔记，但播放跳转不可用。

### 5.3 搜索、收藏与复制

- 「搜索原文或译文」：按关键字筛选。
- 收藏：点击字幕旁的收藏按钮；「只看收藏」只显示收藏的字幕。
- 显示内容：「双语」「译文」「原文」切换。
- 复制：可复制单句，或「复制全部」/「复制筛选结果」。

### 5.4 导出 SRT / VTT / TXT

点击「导出字幕」，选择：

- **导出格式**：SRT、VTT、TXT，UTF-8 编码。
- **范围**：「全部已获得的字幕」或「仅收藏」。
- **内容**：「译文 + 原文」「仅译文」「仅原文」。
- **未完成翻译的条目**：「排除」或「以原文输出并标记 [未翻译]」。
- **临时识别结果**：默认只导出已确认的句子；勾选包含时会标记 `[临时]`。

然后「复制」或「下载」。对话框会显示导出条数、被排除或标记的条数，以及**实际覆盖范围**：

- 只有来源是完整字幕轨道、且确认完整时，才显示「完整字幕轨道」。
- 增量字幕和语音识别得到的内容一律显示为「部分字幕（非全视频）」，并列出已覆盖的时间段和缺口原因（尚未播放到、识别积压、翻译暂停期间、广告、跳转跳过、翻译失败等）。

**部分字幕不代表全片**：你只看了视频的一部分，或中途跳转、暂停翻译，导出文件就只包含实际获得的片段。

**翻译全片后再导出**：来源是完整字幕轨道时，侧栏「字幕」标签会显示「已翻译 N / M 条」和「翻译全片」按钮。开启后，播放位置附近的翻译仍然优先；空闲时每次只发一个请求，按顺序补齐其余字幕的译文（会产生额外调用，遵守暂停、限流和预取开关）。进度到 M / M 后再导出，就能得到完整译文。增量字幕和语音识别来源没有「全片」可译，不显示该按钮。

## 6. 演示模式

演示模式用内置示例数据展示界面和操作流程，用来在未配置服务时了解功能。

- **进入**：设置页「演示模式」→「打开演示模式」（在新标签页打开演示侧栏），或侧栏「设置」标签 →「查看演示模式（示例数据）」。
- **识别方法**：顶部状态显示「演示中」，底部持续显示「演示模式 · 示例数据，不连接视频与服务」；详情中的视频卡片标注「示例视频」；导出内容标注为演示示例。
- **限制**：演示模式不连接 YouTube 视频，不访问你配置的任何服务，不发送请求，不播放声音；授予权限、发现模型、打开工作台等真实操作不可用。
- **退出**：点击底部「退出」或设置中的「退出演示模式」。

真实模式下翻译失败时，**不会**自动切换为演示数据。如果你看到的字幕和视频内容不符，先确认界面上没有演示标识。

## 8. 隐私与数据

### 8.1 数据保存在哪里

所有数据只保存在你这台电脑的浏览器中，不会同步到 Chrome 账号。

| 数据                                        | 位置                                                | 说明                                                                        |
| ------------------------------------------- | --------------------------------------------------- | --------------------------------------------------------------------------- |
| API Key、本地识别配对令牌（默认记住在本机） | 独立 IndexedDB（数据库 `tongting-secure`）          | 扩展重新加载、浏览器重启后保留；YouTube 页面脚本和内容脚本读不到            |
| API Key、本地识别配对令牌（主动取消记住）   | `chrome.storage.session`                            | 浏览器关闭或扩展重新加载后清除；仅扩展可信上下文可读                        |
| 非敏感设置（地址、模型、字幕外观、声音等）  | `chrome.storage.local`                              |                                                                             |
| 连接检查结果、会话恢复记录                  | `chrome.storage.session`                            | 用于扩展后台重启后核对状态                                                  |
| 字幕记录、收藏、笔记                        | IndexedDB（数据库 `tongting`，属于扩展自身 origin） | 用户数据，与翻译缓存分开管理                                                |
| AI 搜索主题、英文词与中文注释               | IndexedDB（同上，最多 20 条）                       | 仅保存在本机；相同主题重新生成会替换原记录，不包含 API Key                  |
| 翻译缓存                                    | IndexedDB（同上）                                   | 有数量（约 5000 条）与时间（30 天）上限，超出后淘汰；「缓存翻译结果」可关闭 |

### 8.2 网络请求去向

- 字幕文本只发送到**你配置并授权的 sub2api 地址**，用于翻译。
- 捕获的音频片段只发送到**你选择的语音识别服务**（本地识别服务在 `127.0.0.1`；或经实测的 sub2api 语音接口）。
- 选择 sub2api 语音合成时，译文发送到你的 sub2api。
- 系统语音由操作系统/浏览器处理，其引擎可能联网，这不由同听控制。
- 同听不包含统计、遥测或第三方分析，不向开发者或其他服务器上传数据。扩展代码、图标和界面依赖都打包在本地。
- 请求不跟随重定向，避免 Key 被发往其他站点。

### 8.3 音频

- 只在你点击开始且需要识别时捕获当前标签页的声音，不使用麦克风。
- 扩展把音频放在内存中分段处理，**不写入磁盘，不保留录音**。停止后释放捕获。
- 本地识别服务如何处理音频见 [ASR_LOCAL.md](ASR_LOCAL.md)。

### 8.4 如何清除

| 要清除的内容     | 操作                                                                                      |
| ---------------- | ----------------------------------------------------------------------------------------- |
| API Key          | 设置页「模型连接」或「数据与隐私」→「删除 Key」                                           |
| 本地识别配对令牌 | 设置页「识别与播放」→「删除令牌」                                                         |
| 翻译缓存         | 「数据与隐私」→「清空翻译缓存」（字幕记录、收藏、笔记不受影响；之后重新翻译可能产生费用） |
| 设置             | 「数据与隐私」→「恢复默认设置」（Key、令牌、字幕记录、收藏、笔记不受影响）                |
| 某条字幕记录     | 字幕工作台左侧删除该记录（该视频的笔记与收藏保留）                                        |
| AI 搜索历史      | 侧栏「搜索」→「最近生成」→「清空历史记录」                                                |
| 笔记             | 在工作台中删除笔记文字                                                                    |
| 访问权限         | `chrome://extensions` →「同听」→「详情」→「网站访问权限」中移除                           |
| 全部扩展数据     | 在 `chrome://extensions` 中移除「同听」，Chrome 会删除扩展的存储与 IndexedDB              |

「导出非敏感设置」生成的文件不包含 API Key 与配对令牌。本地识别服务保存在电脑上的令牌文件和模型缓存需要按 ASR_LOCAL.md 单独删除。

## 9. 故障排查

先看侧栏「翻译」标签顶部的提示或错误卡片，大多数错误都带有下一步按钮。以下按类别列出常见情况（提示文字以实际界面为准）。

### 9.1 sub2api 连接与翻译

| 现象 / 提示                                                              | 原因                                           | 下一步                                                                                                                          |
| ------------------------------------------------------------------------ | ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| 「未配置服务」「尚未配置 sub2api 服务地址与 API Key」，开始按钮不可用    | 缺少地址或 Key                                 | 按[第 2 节](#2-配置-sub2api)填写并保存                                                                                          |
| 「尚未授予扩展访问服务地址的权限」                                       | 未授权，或改了地址后没有为新地址授权           | 设置页点击「授予访问权限」并在 Chrome 弹窗中允许；如果弹窗没有出现，到 `chrome://extensions` →「同听」→「详情」检查网站访问权限 |
| 浏览器重启或重新加载扩展后变成「未配置」                                 | Key 只保存在浏览器会话                         | 重新输入 Key；如需长期保存，勾选「记住在本机」（注意 [2.3](#23-api-key-与保存位置) 的风险说明）                                 |
| 「API Key 无效或已失效（401）」                                          | Key 错误、过期或被停用                         | 到 sub2api 后台确认 Key 状态，重新填写并保存，然后检查连接。扩展不会反复重试 401                                                |
| 「没有使用该模型或接口的权限（403）」                                    | Key 所在分组无该模型权限                       | 在 sub2api 后台检查分组的模型权限，或「发现模型」后换一个实际可用的模型                                                         |
| 「服务提示余额或额度不足」                                               | 余额或分组额度用完                             | 到 sub2api 后台充值或调整额度后，点击「重试」                                                                                   |
| 「繁忙或限流（429）」「服务限流中，稍后自动继续」                        | 请求过快或服务限流                             | 等待自动恢复（会按服务要求的时间退避，并暂停预翻译）；频繁出现时关闭「预翻译后续字幕」，或换用限额更高的分组                    |
| 「服务找不到该模型（404）」「服务不接受该模型 ID」                       | 模型 ID 拼写错误或服务没有该模型               | 核对模型 ID，或从「发现模型」列表中选择                                                                                         |
| 「服务不支持该接口」                                                     | 协议不匹配或 Base URL 错误                     | 核对 Base URL；在「接口协议」中手动切换 Responses / Chat Completions 后重新检查                                                 |
| 「服务不接受本次请求中的某个参数」                                       | 服务不接受推理参数等                           | 「推理参数」改为「不发送」；仍失败时关闭「流式返回」                                                                            |
| 「无法连接到服务」                                                       | 断网、DNS、证书错误、地址错误                  | 在浏览器直接访问该地址确认可达；检查代理、证书和地址拼写；确认已授权该 origin                                                   |
| 「服务返回了重定向……已停止请求」                                         | 地址会跳转（如 http→https、换域名、补路径）    | 把 Base URL 改为跳转后的最终 API 地址，重新授权并检查                                                                           |
| 检查连接「小规模翻译」报格式错误，或提示返回的不是 API 数据              | Base URL 指向了网页而不是 API                  | 确认填写的是 API 根地址（通常与后台登录页不同）                                                                                 |
| 「服务在 N 秒内没有完成响应」「流式响应在结束前中断」                    | 网络慢、模型慢或流式不稳定                     | 在设置中调大「单次请求超时」；关闭「流式返回」；持续出现时检查 sub2api 上游状态                                                 |
| 「服务暂时异常（5xx）」                                                  | sub2api 或上游故障                             | 稍后会自动重试；持续失败请检查 sub2api 后台与上游账户                                                                           |
| 部分字幕显示「翻译失败」                                                 | 个别批次失败或结果校验不通过                   | 点击「重试失败的 N 条」；多次失败时换模型或风格再试                                                                             |
| 视频上的状态显示「部分字幕翻译失败，正在重试」「服务限流，稍后自动重试」 | 连续失败或限流（侧栏顶部有详细原因）           | 等待自动恢复；持续出现时按侧栏提示检查服务                                                                                      |
| 「已停止发送翻译请求：……」「翻译已停止，详见侧栏」                       | 认证、权限、额度问题或连续多次无有效译文而熔断 | 按提示修正后点击「重试失败的 N 条」或重新开始                                                                                   |

仍无法解决时，请记录：Chrome 版本、操作系统、视频类型（普通录播/直播/Shorts，有无字幕）、所用模型与识别服务、界面上的完整提示文字和复现步骤。**不要**在反馈中附带 API Key、配对令牌或含授权参数的 URL。

## 10. 已知限制

- **尚未完成真实验收**：云端识别／合成、真实 YouTube 长时观看、工具栏点击授权下的捕获及真人听感。Luna 文本翻译与本地合成视频的真实识别／中文配音已经验证；范围见 LIVE_TEST.md。
- **本地地址只允许 127.0.0.1**：sub2api 的 http 地址和本地识别服务都不接受 `localhost`（可能解析到 IPv6 上的其他进程）。
- **视频类型**：首批验收对象是普通 YouTube 录播。直播、Shorts、画中画、嵌入其他网站的 YouTube 播放器、`m.youtube.com` 均未验证，不宣称支持。
- **字幕读取依赖 YouTube 页面**：完整字幕轨道读取、广告识别、播放器状态都依赖 YouTube 当前的页面结构，YouTube 改版可能导致暂时不可用。读不到完整轨道时只能读取当前显示的字幕（需要开启 CC，只覆盖已播放部分）。
- **不做 OCR**：画面中烧录的文字不能读取。
- **需要登录或付费才能观看的视频**：同听不绕过任何访问限制。
- **语言支持**：界面列出的目标语言不等于实测支持；翻译质量因语种、模型而异，人名、数字、否定句等可能误译。翻译风格不能提升原文字幕或识别的准确率。
- **延迟**：没有实测数据前不承诺延迟。完整轨道可以提前翻译，增量字幕和语音识别必然晚于原声。
  - 语音识别来源的译文要等一句说完、识别并翻译后才出现，所以画面上显示的是「刚说完的那句」。它会一直显示到下一句译文到达，或该句结束 8 秒后自动隐藏。
  - 使用本地 small 模型、模拟翻译服务、5 秒分段的旧测试中，从一句结束到译文可显示约 2.6–2.9 秒。本轮合成视频加真实 Luna 的单次测试中，第一句结束于媒体 5.579 秒、实际配音约在 10.779 秒开始；这是样本结果，不能当作延迟保证。
- **系统语音**：可用声音取决于操作系统；系统语音可能联网，不保证离线。
- **识别速度因硬件而异**：本地识别服务在 macOS 上只能使用 CPU，不同电脑、模型大小速度差异很大，不保证实时。
- **音频**：同一时间只有一个标签页可以使用同听的音频。捕获期间原声由扩展回放，可能与标签页直接播放的听感略有差异。
- **扩展后台会被 Chrome 回收**：长时间运行中可能需要重新连接；需要捕获声音的会话恢复时可能要求再次点击工具栏图标。
- **计费**：取消请求不代表服务端不计费；清空缓存、切换语言/模型/术语后会重新请求翻译。扩展不显示费用估算。
- **浏览器范围**：仅桌面版 Chrome（≥ 116）；未在 Edge 等其他 Chromium 浏览器上验证。
- **会话内 Key**：默认保存方式下，关闭浏览器、重新加载或更新扩展后需要重新输入 Key。

## 11. 用中文搜索 YouTube

在同听侧栏选择「搜索」，不必先打开视频。此功能复用已保存的 sub2api 连接与翻译模型，默认使用 `gpt-5.6-luna`。

1. 输入想看的内容，例如「新手怎么用 AI 剪辑 YouTube 视频」，最多 300 字。
2. 点击「生成英文搜索词」，或按 `Ctrl/⌘ + Enter`。第一条为输入内容的英文直译，不额外扩展含义；后两条为简短搜索词，优先 2–5 个词，最多 6 个词、60 个字符。每条均附中文注释。旧历史记录保持原样，重新生成后采用新规则。
3. 点击铅笔可修改英文词；「复制」只复制英文；「搜索」在新标签页打开对应的 YouTube 搜索结果，保留当前视频。
4. 展开「最近生成」可载入本机历史，不重复调用 AI；最多保留 20 个主题。同一主题重新生成会替换原记录。

生成期间可以取消；切换到侧栏其他标签、关闭侧栏或更换连接配置也会取消未完成请求。取消不保证服务端停止计费。切换标签会保留中文输入，已有结果可从最近记录载入。

手工编辑不会重新翻译中文注释，也不会改写历史记录；界面会标注注释仍对应原建议。「清空历史记录」只删除 AI 搜索历史，不删除字幕、收藏、笔记或 Key。

点击生成会将输入主题发送给你配置的模型服务；点击搜索会将所选英文词发送给 YouTube。搜索历史仅保存在本机。演示模式使用固定示例，不调用 AI。

若提示没有配置服务，请打开「设置」保存连接和 Key、授予主机权限。若生成成功但历史保存失败，当前结果仍可复制和搜索。若历史损坏，可在「最近生成」中清空后重试。
